## Context

An interactive family web app for Luka's Christmas: a funny mock-up letter from Luka (18 months) to Santa, plus a shared wish list where family members reserve gifts so nobody buys duplicates. See `App design/description.txt` and `App design/design.md`.

## Conventions

- Keep all files for this project inside this folder.
- Update `README.md` when something important is added or changed.
- Never hard-code API keys; use a `.env` file and describe the variables in the README.
